📘 Java Programming – Capstone Assignment
Banking App | Employee Management | Student Result System | Contact List App | Library System

This repository contains the complete implementation of the Java Programming Capstone Assignment for the 3rd semester (B.Tech / BCA / BSc).
Each project demonstrates core Java concepts including OOP, inheritance, polymorphism, exception handling, collections framework, file handling, and method overloading.

📂 Project Overview
1️⃣ Banking Application for Account Management

A console-based banking system supporting:

Creating accounts

Deposits & withdrawals

Displaying account information

Updating contact details

Concepts used:
✔ Arrays
✔ String handling
✔ Java control structures
✔ Scanner-based I/O
✔ Basic OOP

2️⃣ Employee Management System (Inheritance + Polymorphism)

A class hierarchy demonstrating:

Base class: Employee

Derived classes: Manager, Developer

Overriding calculateBonus()

Overloading constructors

Storing employees using polymorphism

Concepts used:
✔ Inheritance
✔ Method overriding
✔ Polymorphism
✔ super keyword
✔ Array of Employee references

3️⃣ Student Result Management System (Exception Handling)

A robust result system that:

Collects student details & marks

Validates marks with a custom exception

Handles invalid input using try–catch–finally

Calculates pass/fail results

Concepts used:
✔ Custom exceptions (InvalidMarksException)
✔ throw & throws
✔ try–catch–finally
✔ InputMismatch handling

4️⃣ Contact List Application (Collections + File Handling)

A feature-rich contact management system using:

HashMap to store contacts

File handling for save/load (BufferedReader/Writer)

Search, add, remove operations

Concepts used:
✔ HashMap
✔ Java File API
✔ Character streams
✔ Collections Framework

5️⃣ Library Management System (Method Overloading)

A simple library application with:

Book storage using an array

Method overloading for book searching

Borrow/return operations

Menu-driven interface

Concepts used:
✔ Method overloading
✔ OOP principles
✔ Arrays
✔ String comparison

🛠 Technologies Used

Java 8+
